# 📊 Superstore Sales Dashboard

Interactive Excel dashboard analyzing sales, profit, shipping performance
and trends for Superstore (Jan 2016 – Dec 2019).

![Dashboard](dashboard.png)

## 📌 Key Metrics
| Metric | Value |
|---|---|
| Total Orders | 5,009 |
| Total Sales | $1,099,816.11 |
| Total Profit | $132,515.74 |
| Total Quantity | 19,044 |

## 🔍 Key Insights
- Sales peak in November and December (about $172K each)
- Chairs are the top-selling sub-category ($166.7K), followed by Phones ($162.4K)
- Sales split: Technology 35%, Furniture 34%, Office Supplies 31%
- Around 65% of orders were delayed
- Some products (e.g. certain 3D printers) consistently make losses

## 🛠️ Dashboard Features
- Monthly sales trend
- Top sub-categories, region and state-wise sales
- Most profitable and most loss-making products
- On-time vs delayed delivery status
- Slicers for Month, Region and Category

## 🧰 Tools Used
Microsoft Excel (Pivot Tables, Pivot Charts, Slicers)
